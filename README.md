# verita
## 1. Apresentação

O Verita é uma plataforma web de educação e transparência alimentar que tem como objetivo auxiliar consumidores a compreenderem melhor os alimentos que consomem, transformando informações nutricionais complexas em conteúdos simples, acessíveis e úteis para a tomada de decisões alimentares mais conscientes.

A plataforma utilizará dados obtidos por meio da API Open Food Facts, uma base de dados colaborativa e aberta sobre produtos alimentícios do mundo inteiro, permitindo que o usuário pesquise ou escaneie produtos para obter informações detalhadas sobre sua composição.

Diferentemente de aplicativos que apresentam apenas tabelas nutricionais e valores calóricos, o Verita busca traduzir informações técnicas em linguagem compreensível, explicando ingredientes, níveis de processamento, presença de aditivos, excesso de açúcar, sódio e gorduras, além de sugerir alternativas alimentares e fornecer conteúdos educativos.

O projeto tem como foco principal promover educação alimentar, consumo consciente e facilitar o acesso à informação, utilizando tecnologia para aproximar o usuário do conhecimento sobre os alimentos que fazem parte de sua rotina.
